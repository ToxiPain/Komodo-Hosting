Preguntas Frecuentes

Resolvemos tus dudas principales para que empieces a desplegar sin complicaciones.

¿Cómo funcionan los despliegues en Komodo Host y qué lenguajes soportan?

Contamos con soporte nativo e instantáneo para proyectos desarrollados en Node.js, Python, Golang y Java. Solo necesitas vincular tu repositorio o subir los archivos directos a nuestro panel para un despliegue optimizado en cuestión de segundos.

¿Cuánto tiempo tarda en llegar la verificación SMS de Komodo Phone?

La recepción del código es inmediata. Al seleccionar la plataforma (WhatsApp o Telegram) y el país de tu preferencia, el número se activa al instante y los SMS de confirmación se muestran en tu panel en tiempo real.

¿Cómo puedo integrar la API de Komodo AI Studio y los modelos Basilisk?

Obtienes tu clave API directamente desde el API Dashboard. Nuestra API es compatible con solicitudes HTTP estándar y SDKs comunes, lo que te permite integrar modelos como Basilisk-e1 o Basilisk-a3.5 en tus bots o aplicaciones con mínimos cambios de código.
